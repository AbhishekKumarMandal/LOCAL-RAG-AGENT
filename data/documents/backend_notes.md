# Backend Engineering Notes

## Java

Java is a general-purpose programming language widely used for backend
application development. It supports object-oriented programming and
runs on the Java Virtual Machine (JVM).

## Spring Boot

Spring Boot is a Java framework used to build backend applications
and REST APIs. It provides auto-configuration, dependency injection,
and embedded web servers.

## Apache Kafka

Apache Kafka is a distributed event-streaming platform. Producers
publish messages to topics, and consumers read messages from those
topics.

Kafka consumer groups allow multiple consumers to share the work
of processing topic partitions.

## PostgreSQL

PostgreSQL is a relational database. It supports SQL queries,
transactions, indexing, and various data types.

The pgvector extension allows PostgreSQL to store embeddings
and perform vector similarity searches.
